# Drawing / Presentation / Game1 render path map
Verified against: e5b75c6 (2026-11-19)
Covers: Drawing/*.cs, Presentation/*.cs, Game1.cs (render path: LoadContent, PresentThisFrame, Draw), Camera.cs (draw transform only)

## What this area is
Everything that turns sim + animator state into pixels. All of it is render-only: it reads the sim after `Step`, writes nothing back, and may use non-deterministic state (`Random`, wall clock).
`Presentation/` is the seam out of the sim: `TelegraphList` (overlay shapes, no graphics types) and `PresentationEventLog` (edge-triggered events deduped by (sim frame, id)).
Boundary: rig solving, clips and `CharacterAnimator` are `Animation/` (Drawing only draws a solved `SkeletonPose`); sim state is read, never mutated (two caveats: `AvalancheForecast` steps and restores the live sim, see traps; `EntityArtSystem.Sync` replaces an entity's render-only `Sprite` field with a `SheetSprite` wrapper, EntityArt.cs:230). Entities construct their `Sprite` from `Sprites.*` in their own ctors; `Sprite` is a Drawing type held on the sim object, synced in `CosmeticUpdateSystem`. `Drawing/` also holds the rig data types (`Skeleton`, `SkeletonPose`, `Affine2`, `SkeletonExamples`) that Animation consumes.

## Files
- `DrawContext.cs` (102): the immediate primitive API over `SpriteBatch` + 1x1 pixel: `Line/Dashed/Box/Rect/RotatedRect/Ring/Stamp/Disc`. Stateless; Begin/End is Game1's. It is the only primitive helper, but not the only pixel drawer: ChunkRenderer, BackWallRenderer, GrassField, DebugOverlayRenderer and the HUDs call `SpriteBatch.Draw(pixel, Rectangle)` directly.
- `Shape.cs`, `Sprite.cs`, `Sprites.cs`, `PrismFigure.cs`, `QuillbackFigure.cs`: vector sprites.
  `Plants/` (plant art, code-built, no sheets): `PlantFigureKit.cs` (`PlantPalette` colours incl. `Team`/`Legal`/`Illegal`/`SeedSwatch`, `PlantFigureKit` upright-figure helpers with `RootY`, `PoseTelegraph` pose-to-`TelegraphList` for the ghost), `SpitterFigure.cs`, `SnapperFigure.cs`, `SiegePodFigure.cs` (parametric: pose, growth, aim, root face, team colour; cached `Get`, uncached `Build`), `PlantGhost.cs` (seed-bar cursor ghost + siege aim line; `Game1.cs:1483`).

## Flow
Update half (not drawing, but it feeds Draw):
1. `Game1.Update` steps the sim (net 1050-1104, offline 1112-1190; creative mode skips step and cosmetics), then `_cosmetics.Update` (Drawing/CosmeticUpdateSystem.cs:71): cursor trail (`MouseTrail`), sprite sync, animator ticks on `simDt` (only if `RunAnimationSolver` and `simDt > 0`), `_attackGlow.Update`, entity art sync, `MotionFx` (`MotionParticles`, on `simDt`), `_particles.Update(dt)`, then `_camera.TrackTarget` (last).
2. `PresentThisFrame` (Game1.cs:580), once per rendered frame: drains `_events.Pending` into particles/VFX/audio, clears the log, then `_hitFeel.Collect` and `_hitFlash.Collect`.

`Game1.Draw` order (Game1.cs):
1. `_screenshots.BeginCapture` (1236) may bind an offscreen RenderTarget; `GraphicsDevice.Clear(Black)` (1238) clears whichever target is bound.
2. Backdrop (1241): `_background?.Draw(sb, camera, screenCenter)`, an `IBackdrop` (`TreeParallaxBackground` if `BackgroundStyle == "trees"`, else `ParallaxBackground`; built in `LoadContent` 795-829 only when `DrawBackground`; null if assets missing). Screen space, own Begin/End (trees: `LinearClamp`, plus Multiply/Screen blend passes for rays; mountains: `LinearWrap`).
3. `_spriteBatch.Begin(transformMatrix: camera.GetDrawTransform(center))` (1243): the one world-space batch, default settings (Deferred, AlphaBlend, LinearClamp), no effect.
4. `_chunkRenderer.Draw` (1252) then `_blobShadows.Draw` (1253). Inside ChunkRenderer.Draw (46-75): `UpdateLightField` -> `BackWallRenderer.Draw` -> `DrawChunk` per chunk (pixel underlay pass, then atlas fill pass) -> `GrassField` Update+Draw -> `DrawOwnership` -> `DrawSpikes` -> `DrawSpikeSeeds` -> `DrawCrystalWave` -> platforms -> `DrawForecast` -> `DrawSprouts`.
5. Entities (1256-1265): `e.Sprite.Draw(_draw)` with `Flash` from `_hitFlash`, or a debug polygon if no sprite. Before players so players overlap them.
6. Player placeholder sprites (1267-1280, gated by `DrawPlayerSprites`).
7. Sprite skins (1285-1327, gated by `DrawPlayerSpriteSkin`; skin from `SkinForPlayer(i)`): `_spriteBatch.End()` (1294/1311, only if some player has a skin), then per player `_elements.Update` (cloak cloth stepped here on render dt) -> `_elements.Draw(front:false)` -> `skin.Draw(cam, anim.Pose, ...)` -> `_elements.Draw(front:true)`, all BasicEffect device draws, then `Begin(transformMatrix: cam)` again (1325, default settings).
8. Debug skeleton (1330-1352, `DebugDrawSkeleton`): `_animator.Draw` -> `SkeletonRenderer`; bodies (1353-1362, `DebugDrawBodies`).
9. Particles (1367) and cursor trail (1368). Telegraphs (1378-1384): `_telegraphs.Clear()`, players' `CurrentAction.Telegraph(...)`, secondary players, then every `ITelegraphSource` entity, then `TelegraphRenderer.Draw(_draw, _telegraphs, _vfx)`.
10. Debug overlays (1387-1498, each behind a `GameConfig.DebugDraw*` flag, except the freeze-frame lattice oracle paths 1475-1492, drawn whenever `ApplyFreezeFrame` filled them; `DebugDrawHitboxes` fills `_debugQueries` and draws it through `TelegraphRenderer` too).
11. `_spriteBatch.End()` (1503): the deferred world batch is submitted here.
12. Dev demos (1507-1517, `DebugDraw{Primitive,Density,Metaball}Demo`), then the glow pass (1521-1549, outside SpriteBatch): `_attackGlow.Draw` (1527; primary through the `GlowTrailField` render-target field when `GlowTrailField` is on, else `GlowRenderer` primitives; secondaries always `GlowRenderer`; plus charge orb), `_attachments.DrawAnimator` for each player (1530/1537). Those two are replaced by `_attachments.ClearHistory()` while `_recorder.IsPlayback`; `_vfx.Update` + `_vfx.Draw` (1542-1543) run regardless.
13. HUD (1551-1589): `_hud.Draw` (own batch), `_bossBars`, `_depthsHud` (stage "depths"), fighter name labels (`DrawFighterNames`), fight HUDs, recorder/stepper/trace lines, creative-mode draw. Each opens its own `Begin`/`End` (screen space, except `FightHud.DrawWorld` with the draw transform and `CreativeMode.DrawWorld` with the UNSHAKEN `GetTransform` + PointClamp, CreativeMode.cs:177).
14. Frame-timing text (1592, `DebugFrameTimings`), toast (1608), net alert (1621, drawn last so it is on top).
15. `_screenshots.EndCapture` (1630): unbinds the target, blits to backbuffer, saves PNG; returns true in `MTILE_SCREENSHOT` mode and Game1 calls `Exit()`. `_prof.EndFrame()` (1636), `base.Draw`.

Telegraph handoff: sim code appends to `TelegraphList` (ActionState.Telegraph, EnemyState, `ITelegraphSource`); `TelegraphRenderer.Draw` (Drawing/TelegraphRenderer.cs:15) walks it in emission order through `DrawContext`; `Sprite` shapes go to `VfxPlayer.DrawInBatch` and the `Fallback` shapes after them are skipped only if that returns true (:35-37).

## Invariants and traps
- Cross-platform: this source compiles under DesktopGL (Core) and KNI (Web re-globs `..\**\*.cs`, MTile.Web.csproj:29). There are no `#if` guards in Drawing/, Presentation/ or Game1.cs; all platform splits are runtime `OperatingSystem.IsBrowser()`: Game1.cs 298/310 (Initialize: saved stages, config load), 462 (level save), 766/797/873/1224 (asset paths), 922 (quit), 931/988 (desktop-only hotkeys, perf dump file); SkeletonExamples.cs:22; ScreenshotSystem.cs:30,38,55. `.fx` shaders (`CapsuleSplat`, `MetaballComposite`) are used only by `SkeletonMetaballRenderer` (the `DebugDrawMetaballDemo` preview); `LoadContent` catches `ContentLoadException` (Game1.cs:721-727) and leaves `_metaballs` null. Confirmed: `Content.Mac.mgcb` omits both `.fx` (Content.mgcb:23-33 has them), and BOTH MTile.Desktop.csproj:78-83 and MTile.Web.csproj:147-163 pick it by an OS condition. So shader-free = any build made on macOS, desktop or web; a web build published from Windows/Linux ships the shaders. Everything else is SpriteBatch/BasicEffect only.
- Reach profile (WebGL): backdrop strips are clamped and tiled by hand, not Wrap-sampled (TreeParallaxBackground.cs:899-901); `SheetBatch` uses a zero origin because flip origin differs between XNA descendants (SpriteSheet.cs:295-298).
- Pass type: anything issuing `DrawUserPrimitives`/`DrawUserIndexedPrimitives` (`PrimitiveBatch`, `GlowRenderer`, `SpriteSkin.Draw`, `VfxPlayer.Draw`, `SpriteAttachmentRenderer`, `CharacterElements`) must be called with no SpriteBatch open, hence the End/Begin split at Game1.cs:1294-1325 and the glow pass after 1503.
- Camera: `GetDrawTransform` includes shake; `GetTransform` does not and is the one `ScreenToWorld` inverts for sim input (Camera.cs:74-91). Draws use the shaken one; culling windows (`ChunkRenderer.UpdateLightField` :502, `BlobShadowRenderer.Draw` :78) use unshaken `_camera.Position`, so BackWallRenderer pads by one cell (:81). `CreativeMode.DrawWorld` draws with the unshaken transform.
- `DrawContext.Box` truncates to int (:55); `Line` clamps thickness to >= 1 (:35); `Disc` is an axis-aligned square (`RotatedRect` with rotation 0), not a circle, despite its "rotated square" comment (:95-101).
- Tint order in tile fills: palette -> variation x light -> damage (ChunkRenderer.cs:548-552), charge last in `FillStrip` (:636). Charged tiles draw a white underlay and skip the silhouette (:565-567).
- `TerrainLightField` rebuilds from scratch every Draw, as a pure function of terrain (no staleness across rollback); `IsSolid` is true for Unloaded cells so world edges draw no silhouette (TerrainLightField.cs:144). Characters are not lit by it.
- `GroundLine` captures a column once and never updates it (GroundLine.cs:16-17, cache 58-67); the back wall depends on that, so digging does not move the line. The cache resets only when the `ChunkMap` instance changes (stage reload, :33); columns with no solid bottom cell are not cached and are rescanned.
- `GrassField` is render-only with its own `Random(12345)` and wall-clock `time` (GrassField.cs:50,54); peers see different grass. It needs no snapshot; it resets when the `ChunkMap` instance changes (:57-63) and re-tests eligibility against live terrain at draw (:143).
- The only mutable statics in Drawing/ (the rest are const tables), all render-only: `Effects._rng` (Effects.cs:11), `Camera._shakeRng` (Camera.cs:27), `MassOrbTextures` (static texture table, null until Game1 builds it, Game1.cs:744). None may be read by sim code.
- `AvalancheForecast` steps the real sim (snapshot, step, restore) while `PresentationEventLog.Muted` is set; offline only, driven from `Update` (Game1.cs:1170-1172), never from Draw.
- `PresentationEventLog` is written from inside `Step` but dedupes by `(simFrame, id)` over a 120-frame window (> rollback window); `Reset()` is needed on stage reload because the frame counter restarts (PresentationEvents.cs:64-108; Game1.LoadStage calls it and clears related state 535-541). Drain once per rendered frame (`PresentThisFrame`), not per Step.
- `HitFlash` and `HitFeel` edge-detect on snapshotted sim stamps (`CombatState.LastHitFrame`, `Entity.HitGeneration`; HitFeel also `LastParryFrame`) rather than events, so rollback replays do not retrigger. `MotionFx` instead edge-detects rendered-frame changes of state (state type, `HasDoubleJumped`, grounded) and may drop/double a puff across a rollback (MotionFxSystem.cs:13-17).
- `VfxPlayer.Update` is called inside `Draw` (Game1.cs:1542), aged by render dt, so VFX age only on rendered frames.
- Animators tick on `simDt` (sim time advanced this frame), particles/camera on render `dt` (CosmeticUpdateSystem.cs:61-71). During recorder playback Draw uses the recorder's captured root/facing, not `AttackGlowSystem.RigRoot` (Game1.cs:1296, 1336).
- `SkinByName` binds every skin to the PRIMARY animator's skeleton and caches a failed load as null (stick figure fallback) (Game1.cs:1219-1230). A skin mirrors via the root `Affine2` scale; the MLS solve stays in canonical facing (SpriteSkin.cs:11-14). Flash is a second additive One/One pass, not a tint (SpriteSkin.cs:427-445).
- `TreeParallaxBackground.BuildStrips` ends with `SetRenderTarget(null)` and does not restore the previous target (:871); it is called only from its `Draw` (:880) on the first Draw and whenever screen height changes, i.e. at Game1.cs:1241, after `BeginCapture` bound the shot target (1236). On such a frame the rest of the frame goes to the backbuffer and the PNG holds only the black clear. Auto-capture fires at frame 20 by default (`MTILE_SCREENSHOT_FRAME`), so it is hit only with frame 1 or a resize on the capture frame. `DensityField`, `GlowTrailField` and `SkeletonMetaballRenderer` save and restore targets instead.
- ScreenshotSystem target uses `PreserveContents` because the glow pass rebinds targets mid-frame (ScreenshotSystem.cs:60-63).
- Profiler scopes in Draw time the CPU cost of building the deferred batch; GPU submit lands in the `present` scope at the `End()` (Game1.cs:1247-1249, 1500-1503).
- `ParticleSystem` is a fixed pool (capacity 2048 in Game1.cs:94); when full, `Spawn` overwrites the oldest particle, so bursts can silently evict others (ParticleSystem.cs:32-34).
- `TelegraphList` storage doubles when a frame exceeds capacity and `Next()` zeroes each slot; `Clear()` only resets the count (TelegraphList.cs:175-182). `Game1` clears it once per Draw (:1378), not in Update, so telegraphs reflect the final sim state of the frame.
- Draw reads `CurrentAction.Telegraph(...)` for the PRIMARY player via `_sim.Player`, not `LocalPlayer`; debug overlays use `LocalPlayer` (Game1.cs:1379, 1410).
- `GlowTrailField` blends with true (One, One), not `BlendState.Additive`; switching it collapses the field (GlowTrailField.cs:38-41).
- Entity depth is draw order only: blob shadows, then entities, then players, then skins; nothing sorts by Y or layer (Sprite.cs:7-8).
- Do not add a second primitive helper or pass a `SpriteBatch` into `Character/` or `Entities/`; `TelegraphList` exists for that (CLAUDE.md; Presentation/TelegraphList.cs:6-21).

## Where to change X
- A new overlay shape for an action/enemy: override `Telegraph(TelegraphList t, ...)` and call `t.*`; a new shape KIND needs `TelegraphList` + `TelegraphRenderer.Draw` switch (:20-39).
- Tile look (colors, bands, outline, charge): `ChunkRenderer.DrawChunk` (517) and its constants (460-490); base colors `TilePalette.cs`; noise `TileVariation.cs`.
- Cave darkness / back wall: `TerrainLightField` constants (decay, MinLight) and `BackWallRenderer` tunables (:21-45).
- Build/sprout/spike/crystal visuals: `ChunkRenderer.DrawSprouts` 131, `DrawSpikes` 257, `DrawSpikeSeeds` 296, `DrawCrystalWave` 350.
- Draw order or a new world pass: `Game1.Draw`; decide whether it lives inside the SpriteBatch (before 1503) or needs its own pass (after).
- Character art: `SpriteSkin.Draw` 387 (render), `SpriteBinding.cs` (data), `Game1.SkinForPlayer` 1207 (which binding per player: `GameConfig.PlayerSpriteBindings[i]`, else `PlayerSpriteBinding`, else P1's), `CharacterElements` for cloaks. Bindings load lazily from `SpriteBindings/<name>.json` (copied beside the binary by MTile.Desktop.csproj:71; into wwwroot by MTile.Web.csproj:99-111).
- A new particle burst: `Effects.cs` preset; trigger from `PresentThisFrame` (sim event) or `MotionFxSystem`/`CosmeticUpdateSystem` (state-derived).
- A new sim->render event: add a `PresentationKind` (PresentationEvents.cs:24), emit with a state-derived id, handle in `PresentThisFrame` switch (Game1.cs:587).
- HUD readouts: `HudRenderer.Draw` (:35); boss bars `BossBarHud`; add a profiler slot in `Initialize` (Game1.cs:281) for a new pass.
- Backdrop: `IBackdrop` implementations; selection in `LoadContent` (Game1.cs:795).
- Plant figures are drawn UPRIGHT in the cell frame (origin cell centre, root at +`PlantFigureKit.RootY`, growing toward -y); `PlantEntity.SyncSprite` rotates the whole sprite onto the real root face. Do not special-case walls/ceilings in a figure.
- The plant overlay (growth arc, buried outline + health tick, kind tells, ghost) is `Telegraph` output, not Sprite: it is world-space and unrotated.
- The ghost reads the sim's own `PlantRules.Evaluate`; never duplicate legality in Drawing. Plant HUD/ghost are seen in the real renderer for all kinds except the siege pod figure (BACKLOG plants entry).
